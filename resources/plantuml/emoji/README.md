The emoji PlantUML draws in text (`<:name:>`) and beside each entry of a files diagram, from the
emoji set its MIT distribution bundles: Twemoji, (c) Twitter, Inc and other contributors, licensed
under CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/), https://github.com/twitter/twemoji.
Each file is PlantUML's own, wrapped in an `<svg>` of its 36 by 36 view where it was not; `emoji.txt`
is PlantUML's index of them, each code with its GitHub name. `PlantUmlEmoji` draws their shapes.
