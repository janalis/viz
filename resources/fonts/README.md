# Mermaid fonts

IBM Plex Mono is bundled under the SIL Open Font License in `OFL.txt`.

The Bold, Italic and BoldItalic TrueType faces come from
[`IBM/plex` at `71f558992315a12ca1f06a2215d57962a1992162`](https://github.com/IBM/plex/tree/71f558992315a12ca1f06a2215d57962a1992162/packages/plex-mono/fonts/complete/ttf).
They accompany the existing Regular face so native SVG and PNG exports preserve
authored bold/italic text without relying on fonts installed on the host.
